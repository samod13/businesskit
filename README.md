# 🚀 BusinessKit MVP — White-Label Booking & CRM Platform

Повноцінний, сучасний та повністю адаптивний веб-додаток **«BusinessKit MVP»**, розроблений за принципом **White-Label**. Додаток дозволяє за **1–2 хвилини** повністю адаптувати брендинг, кольори, контакти та каталог послуг під будь-який локальний бізнес (салон краси, барбершоп, автодетейлінг, кав'ярню, масажну студію чи клініку) через **єдиний конфігураційний файл**.

---

## ⚡ Швидкий запуск додатку (Сервер уже активний!)

Веб-сервер проєкту вже запущений у фоновому режимі. Просто відкрийте у вашому браузері:

👉 **[http://localhost:3001](http://localhost:3001)**  
*(Або `http://localhost:3000`, якщо порт 3000 вільний у вашій системі).*

### Запуск через скрипт (1 клік):
```bash
./start.sh
```
Скрипт автоматично перевірить порти (3000 / 3001 / 8080) та запустить потрібний сервер.

## ☁️ Як опублікувати на Vercel (Deployment in 1 minuto)

Проєкт уже повністю сконфігуровано для Vercel через файл [`vercel.json`](file:///Users/mac/Desktop/B2B/vercel.json) та Git-репозиторій.

### Спосіб 1: Через GitHub (Найпростіший)
1. Створіть новий репозиторій на [GitHub](https://github.com/new) (наприклад, `businesskit-mvp`).
2. У терміналі в папці проєкту виконайте:
   ```bash
   git remote add origin https://github.com/<ваш-username>/businesskit-mvp.git
   git push -u origin main
   ```
3. Перейдіть на [vercel.com/new](https://vercel.com/new), виберіть ваш репозиторій та натисніть **Deploy**.
4. За 30 секунд додаток буде доступний в інтернеті за посиланням `https://businesskit-mvp.vercel.app`!

### Спосіб 2: Через Vercel CLI
```bash
./deploy-vercel.sh
# або
npx vercel
```

## ⏱️ Як адаптувати додаток під нового клієнта за 2 хвилини

Увесь брендинг, стиль, кольори та послуги зосереджені в одному файлі:  
📂 **[`src/config.js`](file:///Users/mac/Desktop/B2B/src/config.js)**

Відкрийте цей файл і змініть такі рядки:

### 1. Інформація про бізнес (Рядки 18–22)
```javascript
businessName: "Ваша Назва",          // Наприклад: "Blade & Barber" або "АвтоСпа 777"
category: "Категорія бізнесу",       // Наприклад: "Чоловічий барбершоп"
tagline: "Ваш фірмовий слоган",      // Короткий слоган або УТП
```

### 2. Логотип та фото обкладинки (Рядки 25–26)
```javascript
logoUrl: "https://посилання-на-логотип.png",  // Квадратний логотип або аватарка
coverUrl: "https://посилання-на-фонове-фото.jpg", // Горизонтальне банерне фото
```

### 3. Фірмові кольори бренду (Рядки 30–32)
> 🎨 **Усі кнопки, бейджі та градієнти автоматично перефарбуються у вказані кольори!**
```javascript
primaryColor: "#d97706", // Основний колір кнопок і активних табів (HEX)
accentColor: "#334155",  // Додатковий акцентний колір (HEX)
currency: "грн",         // Валюта ("грн", "$", "€")
```

### 4. Контакти та графік роботи (Рядки 35–42)
```javascript
contact: {
  phone: "+380 50 123 45 67",            // Номер для дзвінків клієнтів
  address: "вул. Хрещатик, 10, Київ",    // Фізична адреса закладу
  workingHours: "Щодня: 10:00 - 21:00",  // Графік роботи
  instagram: "@your_business_handle",    // Instagram профіль
  telegramBot: "@YourBot",               // Telegram бот або адмін
}
```

### 5. Каталог послуг (Рядки 45–100)
Просто додайте або відредагуйте об'єкти в масиві `services`:
```javascript
services: [
  {
    id: "srv-1",
    name: "Назва послуги",
    category: "Категорія",    // Автоматично створить фільтр у віджеті
    price: 650,               // Ціна
    duration: "45 хв",        // Тривалість
    description: "Короткий опис того, що входить у послугу",
    popular: true             // Позначка хіта продажів 🔥
  },
  // Додавайте інші послуги за цим зразком...
]
```

Збережіть файл — **готово! Додаток повністю забрендовано під нового клієнта.**

## 📱 Функціонал та інтерфейс (100% Ready)

### 1. Клієнтський віджет (Customer App)
- **Інтерактивний фрейм iPhone 15 Pro** із можливістю в один клік перемкнутися на **десктопний повний екран**.
- Динамічний каталог з фільтрами категорій, бейджами хітів, цінами та тривалістю.
- **Онлайн-запис у 3 кліки**:
  1. Вибір послуги.
  2. Вибір дати (динамічні дні тижня з календаря) та вільних годин майстра.
  3. Введення імені, номера телефону (+380...) та побажань.
- **Екран успіху та Telegram-сповіщення**:
  - Анімація підтвердження запису.
  - **Симулятор Telegram Bot Alert**: аудіо-сигнал нового замовлення, спливаюче вікно з деталями та форматований звіт у `console.log`.

### 2. Адмін-панель власника (Admin Dashboard)
- **Жива аналітика**: ліди за день, очікуваний дохід (грн), середній чек, конверсія статусів.
- **Таблиця замовлень із збереженням у `localStorage`** (дані не зникають після оновлення сторінки).
- **Керування статусами**: `🟡 Новий` ➔ `🔵 Підтверджено` ➔ `🟢 Виконано` ➔ `🔴 Скасовано`.
- Пошук за клієнтом, телефоном або послугою.
- Кнопка **«📥 Експорт в CSV»** для завантаження бази лідів у Excel.
- Кнопка **«➕ Тестовий лід»** для миттєвої презентації клієнтам.
- Кнопка прямого дзвінка клієнту (`tel:`).

### 3. White-Label Пресети (1 клік)
Кнопка **«🎨 White-Label Конфіг»** у шапці:
- 4 готові бізнес-пресети:
  1. 💅 **Салон краси & SPA** (*Luxe Studio*)
  2. 💈 **Чоловічий барбершоп** (*Blade & Barber*)
  3. 🚗 **Детейлінг & Автосервіс** (*Apex Auto Spa*)
  4. ☕ **Крафтова кав'ярня** (*Kava Craft*)
- Можливість наживо змінювати кольори та назву в реальному часі.
